# ksplc/docs

**The documents of the KSPL compiler, `ksplc`.** Each is also reached from the package's entry point, [`ksplc/README.md`](../README.md), which maps the compiler's source folder by folder.

## What is here

* [`ksplc/docs/DESIGN.md`](DESIGN.md) — How the compiler works inside: what each stage decides, and why. For whoever changes the compiler.
* [`ksplc/docs/SPEC-tools.md`](SPEC-tools.md) — What each command (`build`, `run`, `fmt`, `lint`, `lsp` and the rest) takes and returns, option by option, and what each diagnostic code means. For whoever runs the compiler.

## Further reading

* [`ksplc/README.md`](../README.md) — what the package is, and the smallest way to use it.
* [`docs/SPEC-documents.md`](../../docs/SPEC-documents.md) — what each kind of document is for, and the direction references may run in.
