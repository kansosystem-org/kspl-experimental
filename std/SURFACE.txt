std/verdict	pass	pub fn pass(desc: U8[])	reports that the test passed. **One line says one thing.** Trailing whitespace is dropped; a `desc` that contains a newline prints a blank line.

std/verdict	run_children #cfg(!freestanding)	pub fn run_children(items: subproc.Job[], work_dir: U8[], arena: Arena$@): List<|Run_out|>	runs children side by side (`jobs`), and returns their runs in order. **The results come in the input's order**, so the code that judges has one form, sequential or parallel. **Each waits at most `DEFAULT_TIMEOUT_MS`**, as `run_child` does unless told otherwise. Caution: **Give each run a `work_dir` of its own.** The outputs are collected there in files of fixed names (`j<number>.out`), so two runs sharing one at once read each other's.
std/verdict	skip	pub fn skip(why: U8[])	reports that the test does not apply on this target, and why. Caution: **Do not skip it silently.** Printing nothing looks like a pass, and a degraded environment looks like "everything passed". This prints the heading's text and the reason.
std/verdict	skip_check	pub fn skip_check(name: U8[], why: U8[])	reports a check this environment cannot run, with the reason. Caution: **Do not pass it with `check(…, true, …)`.** It would read as confirmed, and the `RESULT:` line would not name it.
std/verdict	start	pub fn start(name: U8[])	starts a test, so a run that hangs shows where it stopped. A run that hangs stopped at **the test after the last line printed**. Caution: **Do not write the same thing in the heading and in `pass`.** The line prints the text given to `pass`; the heading's text appears only when `pass` gets an empty text.
