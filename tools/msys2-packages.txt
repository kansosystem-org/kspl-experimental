# The MSYS2 UCRT64 packages CI's Windows job needs, one a line; `#` starts a comment.
# CI's windows-ucrt64 job and the release's Windows build install exactly these
# (.github/actions/msys2-ucrt64/action.yml), and "The environment for each platform" in
# docs/HOWTO-build.md installs them by hand, so what passes in CI is what a person installs.
# What only the Linux job's gates use is tools/msys2-packages-full.txt; `make ci` skips them without it.

# MSYS2's POSIX tools, in /usr/bin, which drive the build.
git        # `git ls-files`, which the convention checks and the suites read the tree through
make       # MSYS2's own make (`make --version` says `Built for x86_64-pc-msys`), not UCRT64's
diffutils  # `diff`, which the self-host compares the two stages' C with, and `cmp`
# The three below are in MSYS2's base install too; each holds commands the Makefile calls.
findutils
grep
coreutils

# The native UCRT64 compiler, in /ucrt64/bin, which builds what ships.
mingw-w64-ucrt-x86_64-clang  # `clang`, which also compiles the LLVM IR that `--to=llvm` emits
mingw-w64-ucrt-x86_64-binutils  # `windres`, which builds ksmd's file icon into its launcher

# ksmd's page and the browser gates (test-ksmd-browser, test-ksagent-chat), in Chrome, which
# CI's runner image installs and a person installs as any program.
mingw-w64-ucrt-x86_64-lld  # `wasm-ld`, which links ksmd's page; `ld.lld` for bare metal too
mingw-w64-ucrt-x86_64-wasi-compiler-rt  # clang's arithmetic helpers for wasm32
mingw-w64-ucrt-x86_64-nodejs  # `node`, which runs the browser checks' scripts

# The library kssrv links for HTTPS, through kstls. `make kssrv` and `make ksmd` build kssrv,
# and test-extract runs kssrv's and kstls's tests with it.
mingw-w64-ucrt-x86_64-openssl
