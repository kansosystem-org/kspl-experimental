# The MSYS2 UCRT64 packages `make ci` needs on Windows, one a line; `#` starts a comment.
# CI's windows-ucrt64 job and the release's Windows build install exactly these
# (.github/actions/msys2-ucrt64/action.yml), and "Windows natively, without Docker" in
# docs/HOWTO-build.md installs them by hand, so what passes in CI is what a person installs.
# A package that only some work needs stays out: that document names it beside that work.

# MSYS2's POSIX tools, in /usr/bin, which drive the build.
git        # `git ls-files`, which the convention checks and the suites read the tree through
make       # MSYS2's own make (`make --version` says `Built for x86_64-pc-msys`), not UCRT64's
python     # `make test-pytools` runs the Python tools' tests under it
diffutils  # `diff`, which the self-host compares the two stages' C with, and `cmp`
# The three below are in MSYS2's base install too; each holds commands the Makefile calls.
findutils
grep
coreutils

# The native UCRT64 compiler, in /ucrt64/bin, which builds what ships.
mingw-w64-ucrt-x86_64-clang  # `clang`, which also compiles the LLVM IR that `--to=llvm` emits
