# The MSYS2 UCRT64 packages `make ci-full` uses on Windows, beyond tools/msys2-packages.txt.
# Install that list first; this one adds the tools of the gates CI runs on Linux alone.
# One a line; `#` starts a comment. "The environment for each platform" in docs/HOWTO-build.md
# installs it with one command. A gate whose tool is missing here fails or skips and says which.

# LLVM's own tools: test-ksos-link and test-ksmd-browser link with them.
mingw-w64-ucrt-x86_64-llvm  # `llvm-objcopy` and `llvm-objdump`, for the bare-metal images
mingw-w64-ucrt-x86_64-lld  # `ld.lld` for bare metal, and `wasm-ld` for ksmd's browser page

# Bare metal (ksos): test-ksos-link and test-ksos-qemu.
mingw-w64-ucrt-x86_64-arm-none-eabi-gcc  # libgcc's soft-float and 64-bit division for ARM
mingw-w64-ucrt-x86_64-qemu  # `qemu-system-arm`, which runs the demos on emulated boards

# ksmd's browser page: test-ksmd-browser.
mingw-w64-ucrt-x86_64-wasi-compiler-rt  # clang's arithmetic helpers for wasm32
mingw-w64-ucrt-x86_64-nodejs  # `node`, which runs the browser test's scripts

# Libraries that ksai's and ksbind's tests link.
mingw-w64-ucrt-x86_64-openblas  # test-blas: ksai's tests with the BLAS backend
mingw-w64-ucrt-x86_64-openssl  # ksbind's TLS tests, in test-extract
