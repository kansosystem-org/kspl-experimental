# kssrv — what is left

**Only what is not done stands here.** A finished stage is deleted, and its result goes into the document of its kind ("Document naming" in [`SPEC-documents.md`](../../docs/SPEC-documents.md)). What spans packages is in [`docs/PLAN.md`](../../docs/PLAN.md). What the server does is in [kssrv](../README.md), and its decisions are in [`kssrv/docs/DESIGN.md`](DESIGN.md).

| | What is left | What marks it as done |
| :-- | :-- | :-- |
| stage 1 | **HTTPS termination.** The server does not answer over TLS, so a page served to other machines goes over plain HTTP. The OpenSSL binding has only a client half, so a server half comes first | `kssrv/tests/main.kspls` fetching a page over TLS from the server |
| stage 2 | **The token is checked from the head.** The server checks the token only after the whole request has arrived. So a client without a token can make the server hold the connection cap × the body cap. `std/http` has to pass on a head whose body has not arrived | `kssrv/tests/local.kspls` sending a head without a token that names a large body, and getting the refusal before sending any of the body |
| stage 3 | **Watching a whole large folder cheaply.** The page asks `GET /api/stat` about each file, which is heavy for a large folder. Adding the OS's notification (inotify / ReadDirectoryChangesW) is decided once that cost shows. Added first, it would be a per-OS implementation that may not be needed | A page over a large folder measured as too slow to ask, and the decision written into "13.10 A page asks the local machine through one protocol" in [`../../docs/DESIGN.md`](../../docs/DESIGN.md) |
| stage 4 | **Telling apart why a write failed.** A failed write or replace answers 500, whether memory or write permission is missing. Telling them apart needs the parent of a name inspected, which belongs in `std/fs`, not in the server. Written into the server first, the code that splits a path would live in two places | `std/fs` reporting the reason, and "How it refuses" in `docs/SPEC-local-server.md` giving each reason its own status |
