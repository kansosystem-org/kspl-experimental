kspeg/engine	Rule_keywords	pub struct Rule_keywords	one rule and the keywords written in its own definition. One element of keywords_by_rule(). It does not follow references into other rules (the same boundary as collect_keywords).
kspeg/engine	Rule_keywords.keywords	pub keywords: List<|U8[]|>$@	those keywords, in the order the grammar defines them

kspeg/engine	Rule_prof	pub struct Rule_prof	what one rule cost, counted rather than timed. **Count only the calls; do not measure time.** A rule is referenced about a million times in one parse, so calling `sys.mono_us()` here would inflate the real work and make the breakdown disagree with the measured total. Caution: **Do not store "how many times it read and failed".** A reference always ends in exactly one of "hit the memo", "read and succeeded" or "read and failed", so that count is `calls - memo_hits - parsed_ok`.
kspeg/engine	Rule_prof.calls	pub calls: I64	how many times it was reached, memo hits included
kspeg/engine	Rule_prof.memo_hits	pub memo_hits: I64	how many of those the memo answered, saving a re-parse. Successes and failures alike. If it stays 0, the rule visits each position once and packrat saves nothing; that is the evidence that adding lookahead would not pay off.
kspeg/engine	Rule_prof.memo_off	pub memo_off: Bool	whether memoization was turned off for this rule. It never answered within its allowance of writes (`memo_trial_writes`). It is reported beside the counts so that a wrong allowance shows up instead of quietly slowing the parse.
kspeg/engine	Rule_prof.name	pub name: U8[]	the rule the counts below belong to
kspeg/engine	Rule_prof.parsed_ok	pub parsed_ok: I64	how many times it actually parsed and matched. Small compared with the failures (the subtraction above), it marks a rule that guesses and misses. Fixing the grammar pays off only where missing is expensive (a rule that reads a whole other rule as a preamble).
kspeg/engine	Space_skipper	pub typedef Space_skipper = fn(ctx: Target$@): Void	a grammar's own way of skipping whitespace
kspeg/engine	Target	pub struct Target	a parse in progress: the source, how far it has read, and what it reads with
kspeg/engine	Target.arena	pub arena: Arena$@	the arena the nodes and the rule table are allocated from
kspeg/engine	Target.checks_first_byte	pub checks_first_byte: Bool	whether a rule that cannot begin with the next byte is skipped. On by default; turned off only to compare against a parse that enters every rule. Either way the tree is the same, and so is a syntax error (parse_rule). The profile counts only the rules entered, and both runs where a syntax error makes it parse twice.
kspeg/engine	Target.depth	pub depth: Sz	how deep the walk of the rule tree is right now. Rule.parse's recursion depth, counted at the single entry point every sequence, choice, quantifier and reference recurses through. A safety valve against pathological nesting.
kspeg/engine	Target.depth_exceeded	pub depth_exceeded: Bool	whether a walk was cut off as too deep, so `pos` is not valid. The reader uses it only to decide **whether the position may be used**; the cut-off itself is thrown as a `fatal`, with its position in `depth_exceeded_pos`.
kspeg/engine	Target.depth_exceeded_pos	pub depth_exceeded_pos: Sz	where the input was at the moment the walk became too deep. Caution: **Record it at once.** Backtracking rewinds `pos` at each level, so by the time the fatal reaches parse_rule, `pos` is back at the start of the input. `max_fail_pos` cannot replace it: it is the furthest place expected text did not match, and a depth cut-off never goes through track_fail.
kspeg/engine	Target.enable_profiling	pub enable_profiling: Bool	whether per-rule counts are kept during the parse
kspeg/engine	Target.fail	pub fail: Fail_track$@	how far the parse got, and what could have been written there. Caution: **Do not put the fields back here** (the reason is at `Fail_track`).
kspeg/engine	Target.free_memo	pub fn free_memo(r: Self$@)	frees what this target owns; the nodes stay. The counts are its own. The memo table and the grammar's name table belong to the lender: only the target that loaded the grammar frees them, once every borrower is done.
kspeg/engine	Target.is_lenient	pub is_lenient: Bool	whether the branches that absorb a broken run are enabled. Those branches are `Rule.recover`. **A whole run is either lenient or not**: it never switches partway, and every run starts with the memo empty (`begin` in `memo.kspls`), so the memo's key need not include it.
kspeg/engine	Target.is_suppressed	pub is_suppressed: Bool	matching only to test: no node is built, no expectation recorded
kspeg/engine	Target.is_syntax_mode	pub is_syntax_mode: Bool	inside an ordinary rule, where whitespace is skipped between parts
kspeg/engine	Target.keywords_by_rule	pub fn keywords_by_rule(r: Self$@): List<|Rule_keywords$@|>$@	every rule and the keywords inside it, except the synthesized one. In declaration order, without following references (as collect_keywords). A rule with no keyword is returned too, for a caller that needs every name. The synthesized `_Keyword`, which bundles what parse_grammar collected, is left out: it would read as one rule holding every keyword of the grammar.
kspeg/engine	Target.load_rules	pub fn load_rules(r: Self$@, rules: List<|Rule_entry$@|>$@)	loads a grammar and resolves its references in one step. Builds the name table, resolves references to indices, looks up `_Space`/`_Boundary` ahead of time and makes the memo table every parse shares, all in one step: skip the resolving and a `reference` fails mid-parse with "an undefined reference". Done in `notation`, the rule table's element type and these steps would leak outside this file.
kspeg/engine	Target.new	pub fn new(source: U8[], arena: Arena$@): Target	a parse of `source`, no grammar loaded yet
kspeg/engine	Target.parse_rule	pub fn parse_rule(r: Self$@, name: U8[]): Node$@?Kspeg_signal	parses the source from the start with that rule and returns the tree
kspeg/engine	Target.pos	pub pos: Sz	how far it has read, in bytes from the start of the source
kspeg/engine	Target.prof_list	pub prof_list: List<|Rule_prof$@|>$@	those counts, in the order the rules were first reached
kspeg/engine	Target.ran_twice	pub ran_twice: Bool	whether the last parse_rule ran again without skipping. Only a syntax error does. On input that parses, it says a rule was skipped where it could have matched: the answer is still right, from the second run, at twice the cost.
kspeg/engine	Target.share_grammar_from	pub fn share_grammar_from(r: Self$@, src: Self$@)	borrows another target's grammar as is. **The memo table is shared with it**: every parse empties the table as it starts, so one table serves them all. If callers assigned the fields themselves, `rules`' element type (kspeg's internal representation) would leak outside the folder, and nothing would say the fields belong together. Caution: **The targets sharing one grammar parse one at a time.** Two at once would write into the same table, each emptying it under the other.
kspeg/engine	Target.source	pub source: U8[]	the text being parsed; a node's `text` is a view into it
kspeg/engine	Target.space_cache_end	pub space_cache_end: Sz	where that skip ended, so the same start is not scanned twice
kspeg/engine	Target.space_cache_pos	pub space_cache_pos: Sz	the position the last skip started from. A one-entry cache: after backtracking, each element of a choice or sequence skips again from the same start, and this jumps to the recorded end instead (the source, space_skipper and rule_space do not change during a scan).
kspeg/engine	Target.space_cache_valid	pub space_cache_valid: Bool	whether the two fields above still match the current position
kspeg/engine	Target.space_skipper	pub space_skipper: Space_skipper	the whitespace skipper, if the grammar provides one
kspeg/expected	Expected	pub struct Expected	one thing that could have come where the parse stopped. Caution: **Do not mix literal text with a rule's name.** Literal text (`';'`) is typed as it stands; a rule's name (`Identifier`) is not, and in the same quotes it reads as though typing `'Identifier'` would work. Only the code that records it knows which, so it is kept.
kspeg/expected	Expected.is_optional	pub is_optional: Bool	whether nothing had to be written here, so it did not stop the parse. An optional or a repetition that gave up before reading a character. **Ignoring this fills the list with ways to continue**: forget a `;` after an expression and every operator is listed at that position before `';'`, though only `';'` stopped the parse. Pass the list through `order_expected` before reporting it.
kspeg/expected	Expected.is_rule	pub is_rule: Bool	whether it is a rule's name rather than text a user types. The report phrases the two differently.
kspeg/expected	Expected.text	pub text: U8[]	the literal text, or a rule's name when `is_rule` is set
kspeg/expected	Fail_track	pub struct Fail_track	one input's failure record: how far it got, and what could go there. Caution: **Do not move the fields back into `Target`**: that makes the import cycle named at the top of this file. There is one per input (`Target` creates and holds it); a `Target` that only lends its grammar leaves its own unused.
kspeg/expected	Fail_track.deepest_try	pub deepest_try: Sz	how far the lexical token being read has got. Caution: **Count only the failures inside the token** (where recording is suppressed). An ordinary rule failing inside it (an expression inside interpolation) records at its own position; counted here too, it would list the token's name at that position as well.
kspeg/expected	Fail_track.demote_expected_since	pub fn demote_expected_since(r: Self$@, prev_pos: Sz, prev_n: Sz)	marks what a dropped branch recorded as not what stopped it. Another branch read the input, so the dropped branch's failure did not stop the parse. **Change only the mark; do not drop the label** (that text can still be written there). If the failure position has advanced, the list was rebuilt, so every label is marked.
kspeg/expected	Fail_track.expected_label_count	pub expected_label_count: Sz	how many of those are in use
kspeg/expected	Fail_track.expected_labels	pub expected_labels: Expected$@	what could have come at that position, up to the cap
kspeg/expected	Fail_track.max_fail_pos	pub max_fail_pos: Sz	the furthest position where an expected spelling did not match. **A failure cut off by depth is not recorded here** (`Target.depth_exceeded_pos` keeps it).
kspeg/expected	Fail_track.new	pub fn new(arena: Arena$@): Fail_track$@	an empty record; its label buffer is allocated once. Caution: **Allocate `expected_labels` here, once.** Allocating per record grows the arena with every failure, and one parse can fail over a million times.
kspeg/expected	Fail_track.order_expected	pub fn order_expected(r: Self$@)	moves what stopped the parse to the front, before reporting. Labels at one position are recorded from the inside outward, so without reordering the fixes (`';'` / `')'` / `'}'`) are buried behind operators that could continue the expression. **Put the rest after them instead of dropping them**: what need not be written can still be written there (after `f(`, both a parameter and a `)` can). Caution: **Keep the order within each group**: inside to outside says which is closest.
kspeg/expected	Fail_track.push_expected	pub fn push_expected(r: Self$@, pos: Sz, e: Expected)	records one thing that could have come at that position
kspeg/expected	Fail_track.reset	pub fn reset(r: Self$@)	empties the record for a new run, keeping its label buffer
kspeg/expected	Fail_track.skippable_start	pub skippable_start: Sz	where the innermost open skippable attempt began, or `no_skippable`. **Save it and restore it.** Attempts nest, so leaving it overwritten makes an outer attempt look at an inner position.
kspeg/expected	Fail_track.track_token_fail	pub fn track_token_fail(r: Self$@, pos: Sz, body: Rule$@, name: U8[])	records that a lexical token could not be read, under its own name. Caution: **Do not record a failure from inside the token as it is** (`character class`, or one inside `_Name`). **Do not check the suppression here**: the caller (parse_reference_impl) has already decided whether to record.
kspeg/expected	max_expected_labels	pub const max_expected_labels: Sz = 8	how many `expected` labels one position may carry. Caution: Keep the number in this one place; with copies, raising one would write past the buffer another sized. **Raising it does not help**: what overflows is the operators that could continue an expression (after `x: = 1`, some thirty are recorded and `';'` comes last).
kspeg/expected	no_skippable	pub const no_skippable: Sz = -1	the position that means "no skippable attempt is open". Caution: **It must be a value that matches no position**: with 0, a failure at the start of the file would count as skippable.

kspeg/rule	First_bytes	pub struct First_bytes	the bytes a match can begin with, and whether it can match nothing. **A rule cannot match where the next byte is not among its bits**, unless it can match nothing; then the bits say nothing about it. engine skips such a rule without entering it. Caution: **Err only on the side of too many bits.** A missing one makes a rule that could match be skipped, and the parse goes another way with nothing to say so.
kspeg/rule	First_bytes.allows	pub fn allows(r: Self@, c: U8): Bool	whether a match can begin with `c`
kspeg/rule	First_bytes.bits	pub bits: U64[4]	bit `c` of the 256 set where a match can begin with byte `c`
kspeg/rule	First_bytes.can_be_empty	pub can_be_empty: Bool	whether it can match without reading a byte
kspeg/rule	Keyword_set	pub struct Keyword_set	keywords folded into one rule: extract one word, then look it up once. words and order hold the same keywords: words for the match, order for the expected labels. Caution: Do not drop order and walk words instead. A Map iterates in hash order, so a syntax error's `expected …` would change from run to run.
kspeg/rule	Keyword_set.boundary	pub boundary: U8[]	`_Boundary`'s ranges, which decide where a keyword ends. Caution: Do not make this a fixed value; a grammar may override `_Boundary`.
kspeg/rule	Keyword_set.order	pub order: List<|U8[]|>$@	the same keywords in the grammar's order, for an `expected` list
kspeg/rule	Keyword_set.words	pub words: Map<|U8[], Sz|>$@	each keyword's index in order, for the lookup itself
kspeg/rule	Kspeg_signal	pub enum Kspeg_signal	what a rule throws: both backtracking and a real failure, in one type. It is one type because the single recursive entry point (Rule.parse) can throw either. Caution: **Sharing a type, the two are easy to confuse.** `catch false` turns even a fatal into "it did not match"; only engine's `try_parse` may swallow one ("A backtracking signal may be swallowed, a real failure may not" in `kspeg/docs/SPEC-notation.md`).
kspeg/rule	Kspeg_signal.fatal	fatal(msg: U8[])	a real failure, to be passed up to the caller and never swallowed
kspeg/rule	Kspeg_signal.mismatch	mismatch	this rule did not match here; try the next alternative
kspeg/rule	Rule	pub enum Rule	one node of the rule tree; each variant is one way of matching
kspeg/rule	Rule.and_pred	and_pred(rule: Rule$@)	matches where this would, consuming nothing and building nothing
kspeg/rule	Rule.char_class	char_class(ranges: U8[])	one byte in these ranges. A byte range X..Y is the 3-byte run "X-Y"; every other byte is a literal (`[a-z0-9_]`).
kspeg/rule	Rule.choice	choice(rules: List<|Rule$@|>$@)	the first of these that matches, tried in order
kspeg/rule	Rule.keyword_literal	keyword_literal(text: U8[])	a literal that must end at a boundary, so it is a whole word
kspeg/rule	Rule.keyword_set	keyword_set(set: Keyword_set$@)	a whole set of keywords folded into one lookup
kspeg/rule	Rule.literal	literal(text: U8[])	these bytes, matched exactly
kspeg/rule	Rule.not_pred	not_pred(rule: Rule$@)	matches where this would not, consuming nothing and building nothing
kspeg/rule	Rule.one_or_more	one_or_more(rule: Rule$@)	this, repeated as often as it matches, but at least once
kspeg/rule	Rule.optional	optional(rule: Rule$@)	this if it matches, and nothing if it does not
kspeg/rule	Rule.recover	recover(stops: U8[])	absorbs input up to one of these, and also marks the run as lenient. Outside a lenient run it matches nothing, so its branch is dead. Caution: **Do not separate the swallowing from the mark**, or a run could set the mark alone (the notation is in "`~\"...\"`: swallowing a run, and the mark of the lenient run" in `kspeg/docs/SPEC-notation.md`).
kspeg/rule	Rule.reference	reference(name: U8[])	another rule, by name, before `load_rules` resolves it
kspeg/rule	Rule.resolved_ref	resolved_ref(rule_id: I32)	that same rule after resolving, referred to by index, not name
kspeg/rule	Rule.sequence	sequence(rules: List<|Rule$@|>$@)	each of these in turn; all must match
kspeg/rule	Rule.wildcard	wildcard	any one byte
kspeg/rule	Rule.zero_or_more	zero_or_more(rule: Rule$@)	this, repeated as often as it matches; zero times is enough
kspeg/rule	Rule_entry	pub struct Rule_entry	one rule of the grammar: its name and its tree
kspeg/rule	Rule_entry.name	pub name: U8[]	the name the grammar gives it
kspeg/rule	Rule_entry.rule	pub rule: Rule$@	the tree that name stands for
kspeg/rule	char_class_matches	pub fn char_class_matches(ranges: U8[], c: U8): Bool	whether one byte is in a character class's ranges. Caution: Do not interpret a character class anywhere but here. If the code that re-reads `_Boundary` (keyword_set) disagreed, where a keyword ends would depend on where it is matched.
kspeg/rule	collect_keywords	pub fn collect_keywords(rule: Rule$@, keywords: List<|U8[]|>$@)	every keyword the rule matches, in the order the grammar writes them
kspeg/rule	collect_references	pub fn collect_references(rule: Rule$@, names: List<|U8[]|>$@)	every place where this rule refers to another rule by name. `resolved_ref` is skipped: its name is already resolved.
kspeg/rule	compute_first_bytes	pub fn compute_first_bytes(entries: List<|Rule_entry$@|>$@)	fills in each rule's `first`, once its references are resolved. **A fixed point**: a rule's bytes depend on the rules it begins with, which may refer back. Each round only adds bits and empties, so it ends after a few rounds over the grammar.
kspeg/rule	fold_keyword_choices	pub fn fold_keyword_choices(rule: Rule$@, boundary: Rule$@, arena: Arena$@)	turns each run of keywords inside a choice into one set lookup. A run of keywords in a choice folds wherever the set may (keyword_set_boundary): each matches only the whole run of boundary characters, so at most one can match at a position and their order decides nothing. The alternatives around the run keep their places, and the set records the labels the run would have, so folding changes neither a tree nor a syntax error.
kspeg/rule	keyword_set_boundary	pub fn keyword_set_boundary(boundary: Rule$@, keywords: List<|U8[]|>$@): Option<|U8[]|>	the ranges to fold a keyword set on, or `.none` where it cannot. It folds only where the boundary check means "the whole extracted word matches": `_Boundary` is one character class, and no keyword is empty or holds a byte outside it (`'->'`). Caution: Do not fold where these do not hold: `_Keyword` then always fails, and in a grammar that writes `!_Keyword`, an identifier swallows a reserved word.
kspeg/rule	keyword_set_rule	pub fn keyword_set_rule(keywords: List<|U8[]|>$@, ranges: U8[], arena: Arena$@): Rule$@	one rule matching any of these keywords with a single lookup. Caution: **Call it only where keyword_set_boundary answered `ranges`.** Elsewhere the scan that cuts the word out does not stop where the keyword ends.
kspeg/rule	left_recursive_rule	pub fn left_recursive_rule(entries: List<|Rule_entry$@|>$@): Option<|U8[]|>	a rule that can enter itself before reading a byte, if any. Such a rule never matches: each entry enters it again at the same position, until the depth limit stops the parse. Call it after compute_first_bytes, which says what can be empty.
kspeg/rule	max_parse_depth	pub const max_parse_depth: Sz = 3000	how deep the rule tree may be walked before it gives up. Pathologically deep nesting (a long run of `(`) becomes a compile error at a depth ordinary code never reaches, **the same on every build**. The stack cost per level differs by backend (LLVM and MSVC use more than clang's C), so the walk also stops near the stack's end (`walk_limit` below). engine's Rule.parse and notation's parse_primary check both.
kspeg/rule	reads_in_syntax_mode	pub fn reads_in_syntax_mode(name: U8[]): Bool	whether a rule of this name skips whitespace. A rule named with a lower-case initial reads in syntax mode. An upper-case one is a lexical token and a `_` one is transparent; neither skips ("A rule's name sets its mode" in `kspeg/docs/SPEC-notation.md`).
kspeg/rule	walk_limit	pub fn walk_limit(): Stack_limit	where a walk on the current thread stops, short of the end of its stack. **The second limit, next to the depth count**: a short stack fails with the same "nesting too deep" instead of crashing. Create it on the thread where the walk runs. Caution: **Keep the margin wide.** One level's calls, and the throw with its message, still run below the point that checked.
