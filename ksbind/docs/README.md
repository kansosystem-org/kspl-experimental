# ksbind/docs

**The documents `ksbind` carries.** Each is reached from the package's entry point, [`ksbind/README.md`](../README.md).

## What is here

* [`ksbind/docs/DESIGN.md`](DESIGN.md) — why the bindings stand apart from `std`, how a C macro and C's `long` are reached from KSPL, and what each binding guards against.

What the package publishes is not written here: `ksplc doc ksbind` lists every file, and `ksplc doc ksbind/<file>` gives one file's declarations, rendered from the sources when asked.
