# ksbind/docs

**The documents of `ksbind`, KSPL's bindings to OpenSSL and SQLite.** Each is reached from the package's entry point, [`ksbind/README.md`](../README.md).

## What is here

* [`ksbind/docs/DESIGN.md`](DESIGN.md) — why the bindings stand apart from `std`, how KSPL reaches a C macro and C's `long` type, and what each binding guards against.

The list of what the package offers is not kept here. `ksplc doc ksbind` lists every file, and `ksplc doc ksbind/<file>` gives one file's declarations; both are read from the sources each time you ask.
